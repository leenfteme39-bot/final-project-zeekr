## project Description 
מערכת פול-סטאק לניהול והצגת רכבים חשמליים, הכוללת התחברות משתמשים, העלאת קבצים, שליחת הודעות ומפה אינטראקטיבית.

##Technologies
-React
-Node.js
-Express
-MongoDB
-Firebase Authentication
-Firebase Storage
-Google Maps API
-NodeMailer 

## Main Features
- User registration and login
- Vehicles / services display
- Vehicle / service details page
- File upload
- Contact form
- Email sending

## How to Run the Project

### Client
cd client
npm install
npm run dev

### Server
cd server
npm install
npm run dev

## Environment Variables
Create .env files based on the .env.example files.

morad:
בפרויקט הזה בניתי מערכת Client-Server באמצעות React. במהלך העבודה יצרתי מספר עמודים ורכיבים, עיצבתי את הממשק וחיברתי בין המסכים השונים. בנוסף עבדתי על חוויית משתמש נוחה ועל התאמת המערכת למסכים בגדלים שונים.

בפרויקט השתמשתי ב-React לבניית ממשק המשתמש בצורה מודולרית באמצעות קומפוננטות, מה שמאפשר קוד מסודר וקל לתחזוקה. השתמשתי ב-JSX כדי לשלב בין JavaScript לבין מבנה ה-HTML של הדפים. כמו כן השתמשתי ב-CSS לעיצוב המערכת, מיקום האלמנטים, שינוי צבעים, גדלים והתאמת העיצוב למובייל ולמחשב באמצעות Responsive Design.

לצורך ניווט בין העמודים השתמשתי ב-React Router, שאפשר מעבר מהיר בין מסכים ללא רענון הדף. בנוסף השתמשתי ב-useState לניהול נתונים דינמיים שמשתנים בזמן השימוש במערכת, וב-useEffect לביצוע פעולות בעת טעינת קומפוננטות או בעת שינוי נתונים.

במהלך הפיתוח עבדתי עם JavaScript לטיפול באירועים כמו לחיצות על כפתורים, בדיקות של שדות קלט, שמירת נתונים והפעלת פונקציות שונות. השתמשתי גם ב-localStorage לשמירת מידע בין עמודים כך שהנתונים נשמרים גם לאחר מעבר בין מסכים.

בנוסף למדתי כיצד לחלק את המערכת לקומפוננטות נפרדות, להעביר מידע בין רכיבים, לנהל State בצורה נכונה ולבנות קוד קריא ומסודר. עבדתי גם על בדיקות ותיקון שגיאות (Debugging) כדי לוודא שהמערכת פועלת בצורה תקינה.

הפרויקט עזר לי להבין טוב יותר את עקרונות העבודה של React, את מבנה ה-Client וה-Server, את תהליך בניית ממשק משתמש מודרני ואת החשיבות של קוד מאורגן, יעיל וקל לתחזוקה. אני מרגיש שהפרויקט חיזק את הידע שלי בפיתוח Web ונתן לי ניסיון מעשי בעבודה עם טכנולוגיות מודרניות.
